# Website redesign handoff

This packet is an implementation guide for your existing Astro website. It does not change your live site.

1. Open your existing `website` folder in VS Code.
2. Copy the contents of this packet's `docs` folder into your existing `website/docs` folder. These are new filenames; preserve all existing briefs, worklogs, and session notes.
3. Open `docs/REDESIGN_PROMPT.md` and paste its contents into your Codex chat.
4. Let Codex implement the brief and leave a local preview running. Review the preview yourself.
5. Publish only after you like the result, using Git commands Codex explains for you to run.

The detailed requirements are in `docs/REDESIGN_BRIEF.md`. The four supplied screenshots are in `docs/reference-images/`. They are implementation references and must not be published as site assets.

Keep working in the existing project. Do not create another Astro project, install React, or replace your repository with this packet.
